# MathematicaMathFun: A Computational Odyssey

This repository is a vast collection of Mathematica scripts (`.wls`) and notebooks
(`.nb`) exploring a wide array of mathematical disciplines. Due to its size and
diversity, the documentation is divided into thematic deep dives.

## 📂 Thematic Indexes

- **[Iterative Dynamics & Functional Calculus](./MathematicaMathFun/IterativeDynamics.md)**
  Exploring the behavior of functions under repeated application, fractional
  iteration, and geometric interpretations of dynamics.
- **[Formal Languages & Grammar](./MathematicaMathFun/FormalLanguages.md)**
  Treating mathematical processes (like the Collatz conjecture) as string
  rewriting systems and state machines.
- **[Economic Modeling & Data Analysis](./MathematicaMathFun/Economics.md)**
  Using real-world data (GDP, inflation) to build predictive models and
  visualizations.
- **[Analysis & Geometry](./MathematicaMathFun/AnalysisGeometry.md)**
  Investigations into complex analysis, differential geometry, and spectral
  theory.
- **[The Lab (Experimental)](./MathematicaMathFun/Experimental.md)**
  A collection of "graveyard" or highly experimental scripts where new ideas
  are tested and sometimes abandoned.

## 🚀 Getting Started

Most files are `WolframScript` (`.wls`) files and can be run from the command
line if you have the Wolfram Engine installed:

```bash
wolframscript -file projects/MathematicaMathFun/wls/some_script.wls
```

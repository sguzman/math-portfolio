# MathWhiteBoard

This repository serves as a digital scratchpad for mathematical ideas, primarily
focusing on the visualization of complex expressions using graph structures.

## 🕸 Expression Graphs

The core of this project is the conversion of mathematical expressions into
directed graphs (DOT format) for visualization via Graphviz.

- **Automated Visualization**:
  - `graphs/expressions/normal/`: Contains several `.dot` files representing
    normalized expressions.
  - `output/`: Pre-rendered versions of these graphs in multiple formats (PNG,
    PDF, SVG, JPEG).
- **Key Files**:
  - `1.dot` through `5.dot`: Progressive iterations of expression trees.
  - `normalized.dot`: The canonical representation of a simplified mathematical
    expression tree.

## 🎨 Visualization Formats

The project supports a wide range of output formats to facilitate inclusion in
various research documents, including vector (SVG, PDF) and raster (PNG, JPEG).

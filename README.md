# Math Portfolio

Welcome to my centralized hub for mathematics. This repository captures, systematizes, and renders legible my work across various subfields of mathematics, research notes, and computational experiments.

My mathematical journey is spread across several specialized repositories, now unified here as submodules. Each project represents a different facet of my exploration, from formal research to rough whiteboard sessions and Mathematica-driven simulations.

## 🛠 Structure

- `/projects`: Contains git submodules of individual math repositories.
- `/notes`: Curated markdown notes explaining the significance, context, and key findings within each project.
- `/drafts`: (Coming Soon) Place for in-progress work before it's ready for a dedicated repo.

## ✍️ Methodology

I use **Wolfram Mathematica** for heavy computational lifting and visualization, coupled with **LaTeX** and **Markdown** for documentation. This portfolio serves as a "living document" that I update as my research evolves.
